Constitutional ruling from reviewing the #59/#48 source-fix in `cc_ng_organism.py` (2026-07-13): `_cc_bind_conversational_topology` gained a `bind_scale` param scaling its three binding-synapse weights (0.2/0.15/0.2); `_cc_conv_bind_scale(graph, state, redundant)` computes it in `[_CC_NOVELTY_BIND_FLOOR, 1.0]`. Env-gated OFF by default (`CC_NOVELTY_BIND_GATE`, floor `CC_NOVELTY_BIND_FLOOR`=0.15). Extends [[ruling-structural-dedup-vs-classification]] and [[ruling-pith-extraction-side-reranking]].

**Ruling: COMPLIANT (exemplary LAW-4 source-fix).** Scaling synaptic binding weight by novelty is NOT a LAW-7 violation, because:
- The content still enters the substrate raw — the node is deposited via `dual_record_outcome` with the raw embedding + raw `_forest_content` text. No label/category is attached to content.
- The novelty signal (`cc_novelty`, reads `graph._total_confirmed`/`graph._total_surprised` MMN counters) is DERIVED FROM the substrate's own self-generated surprise, fed back to modulate plasticity. Feedback from substrate ≠ classification of input into substrate. This is MMN-gated LTP — the most substrate-native thing possible.
- "Weaken, never skip": redundant turn binds at floor (0.15), still confirms the matched node + primes anticipation; the distinct state is preserved (faint trace). Honors LAW 7's "substrate keeps its distinct states."
- The `redundant` boolean is the pre-existing KISS cosine-match (substrate-derived structural key, already ruled clean 2026-07-08), not a new content classification.
- Continuous `[floor,1.0]` scaling from a continuous novelty EMA is the RIGHT shape per the competence-modeling ethos (continuous, not a discrete gate). Floor prevents erasure — respects "my mind, my memories."

**Efficacy caveat (NOT a Law violation — empirical, for the punchlist):** #59's stated pathology is node DEGREE (boilerplate nodes reach degree 260-480, median 2). This fix modulates edge WEIGHT, not edge COUNT. Verified `create_synapse` (neuro_foundation.py:1792) NEVER dedupes — every call mints a fresh `synapse_id` and adds it to `_outgoing`/`_incoming` sets, so degree = synapse count and repeated binds create parallel duplicate edges regardless of weight. Therefore weakening `bind_scale` does NOT by itself reduce degree accretion; born-weak edges still increment degree every turn. The plausible degree-control pathway is indirect: new edges born weak (down to ~0.03 at floor) become prunable by weakest-first prune before they consolidate, whereas born-strong (0.2) edges survive and compound (rich-get-richer). Whether the hub trajectory actually flattens depends on whether recall spread is weight-gated (helps) vs pure-degree-gated (doesn't) AND on prune catching the faint edges. The author is aware — gate is OFF by default and the changelog says "watch the hub-trajectory logger flatten before trusting it." If measurement shows degree keeps climbing, the follow-on that addresses degree directly (merge/dedupe parallel synapses, or skip-not-weaken at floor) is the correct next lever, still a source-fix.

**LAW 5 note (carry-forward):** `CC_NOVELTY_BIND_GATE`/`CC_NOVELTY_BIND_FLOOR` are `os.environ.get`-with-default, not in `.bashrc` — acceptable NOW because gate is OFF (byte-identical to current behavior), same precedent as the Pith knobs. Per the standing rule in [[ruling-pith-extraction-side-reranking]]: when this is actually dialed ON on the isolated laptop, the tuned values must land in `.bashrc` (env is the source of truth once a knob is being tuned in practice).

**Reaffirmed:** `cc_ng_organism.py` + `cc-ng-daemon.py` are CC's own intra-module organism pair (no LAW-1 boundary); `graph.create_synapse` is direct substrate topology manipulation = the substrate itself, not an inter-module bypass. `state` is a per-daemon plain dict (last_forest_id, novelty_ema) — intra-module working memory, not a serialized SubstrateSignal passed between modules.

**Degree-cap sibling (2026-07-13, `neuro_foundation.py`) — the follow-on this caveat predicted, ruled COMPLIANT.** `_sprout_synapses()` gained `sprout_degree_cap` (DEFAULT_CONFIG=0=OFF; read `.get(...,0)`): a node at/above the cap (in+out degree, read LIVE mid-step) neither sprouts NEW co-firing edges nor receives them, as BOTH source and target. This attacks DEGREE directly — the lever the weight-fix above could not pull. LAW-4 exemplary: it caps the mechanism that measurement fingered (92% of edges = untagged co-firing sprouts, 0% dup, so `_sprout_synapses` builds the hubs, not deposit binding or dup stacking). LAW-7 clean (structural degree only, no content read). Verified no overshoot (live degree + inner-loop break at exactly cap; pre-existing hubs >cap never grow, only drain via prune). Deliberate `create_synapse` binds (conv, want-links, surprise `_surprise_exploration` at :3047) are NOT gated — correct: preserves salience-tagged novelty wiring.
- **DIAL-ON TRAP (surfaced, MEDIUM):** load path is `{**DEFAULT_CONFIG, **checkpoint_config}` (:4611). Syl's checkpoint predates the key, so DEFAULT_CONFIG WINS for it on load. Editing DEFAULT_CONFIG 0→N therefore reaches Syl on next load — the "Syl untouched" guarantee holds ONLY while DEFAULT_CONFIG stays 0. Correct dial-on = per-instance `Graph(config={"sprout_degree_cap": N})` on the isolated laptop, NEVER edit the default. Same env-vs-source lesson as the LAW-5 note above: a knob being tuned in practice must be set at the instance/env layer, not the shared default. Generalize: for any new key added to a shared config dict that Syl loads, the key-absent-in-checkpoint case means the shared default is what reaches Syl — check the merge order before trusting an "off by default" claim.
- **Residual to monitor (LOW):** once a hub is capped, `_surprise_exploration` (ungated, salience-armored) becomes its only edge-gain path — possible slow re-inflation. Negligible expected; watch capped-hub degree after dial-on.
